# 3D-Object-Detection
This project implements real-time 3D object detection using MediaPipe Objectron and OpenCV. The current setup is configured to detect cups using your device’s webcam and visualize the detected object in 3D with landmarks and axis.

🧠 Features
Real-time 3D object detection

Detection of multiple objects (up to 5)

Visualization of object landmarks and 3D axes

Uses MediaPipe's pre-trained Objectron model

📦 Requirements
Install the required libraries using pip:

#pip install mediapipe
#pip install opencv-contrib-python

🚀 How to Run
Clone the repository or copy the Python script.

Run the script:
#python objectron_detection.py
